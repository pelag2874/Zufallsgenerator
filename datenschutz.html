2. Hosting über GitHub Pages (Server-Logfiles)

Diese Webseite wird auf den Servern von GitHub Inc. (88 Colin P. Kelly Jr. St, San Francisco, CA 94107, USA) gehostet („GitHub Pages“).

Wenn Sie diese Webseite aufrufen, erhebt und speichert GitHub automatisch Informationen in sogenannten Server-Logfiles, die Ihr Browser automatisch an GitHub übermittelt. Dazu gehören:

  • Ihre IP-Adresse
  • Datum und Uhrzeit der Serveranfrage
  • Browsertyp und Browserversion
  • Verwendetes Betriebssystem
  • Referrer URL (die zuvor besuchte Seite)

Diese Daten sind für den technischen Betrieb, die Sicherheit und die Stabilität der Server zwingend erforderlich. Die Rechtsgrundlage für diese Verarbeitung ist das berechtigte Interesse des Hosters (Art. 6 Abs. 1 lit. f DSGVO), einen sicheren Webseitenbetrieb zu gewährleisten. Ich selbst habe keinen direkten Zugriff auf diese Logfiles.

Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub.

3. Lokale Speicherung im Browser (LocalStorage / SessionStorage)

Diese Webseite nutzt die lokale Speicherfunktion Ihres Browsers (auch bekannt als „Web Storage“ oder „LocalStorage“ bzw. „SessionStorage“), um generierte Daten oder Einstellungen direkt auf Ihrem Gerät zu sichern.

  • Welche Daten? Es werden ausschließlich die für die Funktionalität des Zufallsgenerators notwendigen Werte gespeichert.
  • Wo werden die Daten gespeichert? Die Daten verbleiben vollständig auf Ihrem eigenen Gerät. Sie werden zu keinem Zeitpunkt an mich, an GitHub oder an sonstige Dritte übertragen.
  • Wie kann ich die Daten löschen? Sie können diese Daten jederzeit selbst löschen, indem Sie den Browser-Verlauf bzw. die Webseitendaten in den Einstellungen Ihres Browsers leeren oder das Browserfenster schließen (bei SessionStorage).
